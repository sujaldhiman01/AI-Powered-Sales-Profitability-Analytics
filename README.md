# 🤖 AI-Powered Sales & Profitability Analytics

An interactive **Sales & Profitability Analytics** project built using **Python and Power BI** to analyze business performance, identify key sales insights, and forecast upcoming sales.

## 📌 Project Overview

This project transforms raw sales data into meaningful business insights using Python for data analysis and Power BI for interactive visualization.

The dashboard focuses on **sales performance, profitability, customer analysis, product performance, regional performance, and future sales forecasting**.

## 🎯 Objectives

* Analyze sales and profitability performance
* Identify top customers and products
* Compare regional performance
* Understand sales trends
* Forecast sales for the next 3 months
* Generate actionable business insights

## 🛠️ Tools & Technologies

* 🐍 **Python**
* 📊 **Power BI**
* 🔢 **DAX**
* 📁 **CSV / Excel**

## 📊 Dashboard Features

### 1. Sales & Profitability Dashboard

* Key Performance Indicators (KPIs)
* Sales performance analysis
* Profitability analysis
* Sales trends
* Customer and product analysis
* Regional analysis
* Interactive filters and slicers

### 2. 💡 Business Insights

The insights page highlights:

* Top customers
* Top-performing products
* Regional performance
* Important sales trends
* Business performance patterns

### 3. 📈 Sales Forecasting

A **Next 3 Months Sales Forecast** provides an estimate of upcoming sales performance and can support sales and inventory planning.
